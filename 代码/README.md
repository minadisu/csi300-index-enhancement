# 研究代码

本目录用于上传以下项目文件，目前仅包含目录说明。

| 文件 | 用途 |
|---|---|
| 指数增强策略.ipynb | 聚宽研究笔记本：因子获取、预处理、动态筛选、分层抽样和月度回测 |
| 沪深300指数增强回测代码.py | 聚宽交易回测：执行研究端生成的目标权重 |
| 指数增强策略.html | 可选的笔记本展示版本 |
| 输出/ | 经检查可公开的汇总结果与图表 |

## 上传方法

在本目录点击 **Add file → Upload files**，选择准备好的文件，再点击 **Commit changes**。
从目录内上传时选择文件本身，避免再次套入一个“代码”文件夹。

## 上传前处理

- 笔记本先清除执行输出，检查单元格内容、元数据、绝对路径与身份信息。
- 原始交易脚本包含 Base64/Gzip 编码的历史目标持仓；公开前应移除该数据，改为读取自己在授权环境中生成的 CSV，并相应修改读取函数和说明。
- HTML 可能保留数据表、图片和旧输出；应在笔记本清理完成后重新导出。
- 原交易脚本与研究端信号存在时点核对需求：当日收盘后才能确定的信号不能用于当日早上的交易。完成修正后须重新回测，不能继续将旧业绩标作新版本结果。
- 原代码依赖聚宽平台的 jqdata、jqfactor 及回测接口。安装根目录 requirements.txt 不足以在本地直接运行完整策略。

代码尚未上传，本目录不提供已验证可运行的策略版本。

# 回测结果与图表

本目录保存经检查可公开的研究汇总结果。当前尚未上传实际结果。

建议优先上传：

- 整体绩效表：performance_v3.csv
- 分阶段绩效表：performance_by_period_v3.csv
- 策略与基准净值图
- 策略与超额回撤图

每份结果应标明对应代码版本、回测区间、费用假设及研究端/交易端口径。

原项目输出目录中的 .csv.url 文件只是下载快捷方式。若需要展示结果，应从自己的授权环境导出真正的 CSV 或图片，并检查公开权限与内容。
原始因子面板、逐股评分和目标持仓明细不放入本目录。

上传时进入本目录，点击 **Add file → Upload files**；本地目录名建议统一为“输出”，去掉末尾的特殊符号。

# csi300-index-enhancement
# 沪深300指数增强策略研究

CSI 300 Index Enhancement · Dynamic Factor Selection & Stratified Sampling

本项目以沪深300指数成分股为研究对象，通过多因子打分、动态因子筛选与行业—市值分层抽样构建增强组合，研究在控制组合相对基准偏离的同时获取超额收益的方法。

项目使用 Python 和聚宽（JoinQuant）研究环境，覆盖因子构建、数据预处理、组合构建、绩效评估及交易回测验证。

> 当前仓库为项目展示框架，代码、报告和回测结果将陆续上传。

## 研究框架

1. **股票池构建**：按调仓日期获取沪深300成分股，过滤 ST、新上市及交易不活跃股票。
2. **因子构建**：涵盖估值、盈利、成长、技术、波动率、流动性和规模等维度。
3. **预处理**：进行缺失值处理、MAD 去极值、行业与市值中性化、标准化及对称正交。
4. **动态筛选与加权**：结合滚动 Rank IC、ICIR 和 IC 正向占比筛选因子，形成综合得分。
5. **组合构建**：按行业和市值分层选股，结合换手控制、个股权重限制和动态主动风险预算形成目标组合。
6. **回测评估**：分别开展研究端月度回测与聚宽交易回测，分析收益、跟踪误差、信息比率、回撤和换手率。

## 运行环境与复现

研究代码使用聚宽环境中的 `jqdata`、`jqfactor` 及其平台接口。普通 Python 依赖见 `requirements.txt`。

建议复现流程：

1. 准备具有相应数据权限的聚宽账号。
2. 将研究笔记本上传至聚宽研究环境。
3. 检查样本区间、调仓频率、因子筛选参数与缓存设置。
4. 依次运行各单元，生成因子评分、目标权重及月度绩效结果。
5. 根据交易脚本的数据读取方式导入目标权重，再进行交易回测。
6. 核对信号生成时间与成交时间，确保交易只使用当时已经可获得的信息。

本地 `jqdatasdk` 是另一种数据访问方式，不能通过简单替换导入语句完整替代聚宽研究和回测环境。官方使用说明见 [JQData SDK](https://github.com/JoinQuant/jqdatasdk)。

数据获取受账号权限、历史覆盖范围、调用额度及平台服务条件限制。安装 Python 依赖不代表已经获得数据访问权限。

## 数据与公开范围

- 原始行情、财务数据、完整因子面板及持仓明细由使用者在授权环境中自行获取或生成。
- 上传笔记本前检查输出、元数据及代码中的账号、密码和个人信息。
- 研究报告公开版应删除学号、班级、联系方式及文档中的个人元数据。
- 券商研报仅保留必要的参考文献信息，不上传原文附件。
- `.csv.url` 是下载快捷方式，不是 CSV 数据文件，不作为回测结果上传。
- 代码中压缩或编码保存的数据同样需要检查，不能因其嵌入脚本而忽略公开权限。

## 研究局限

本项目属于历史回测研究。财务数据时点、信号与成交时间对齐、参数选择、交易成本及约束可行性均可能影响结果。

按年份划分绩效区间不等于完成严格的样本外验证；仍需核查参数确定过程，并进行独立的样本外检验。历史回测表现不代表未来收益。

# 数据来源与获取说明

## 数据来源

项目使用聚宽（JoinQuant）研究环境，研究对象为沪深300指数（000300.XSHG）。
数据涉及历史指数成分股及权重、股票行情、估值、财务指标、行业分类与交易状态。

本目录仅提供说明，不随仓库提供原始行情、财务数据库、完整因子面板或逐股持仓明细。使用者须通过自己的账号，在相应授权范围内获取或生成数据。

## 获取流程

1. 按月取得当期指数成分股，过滤 ST、新上市及交易不活跃股票。
2. 获取行情、估值、财务、市值和行业数据，形成原始因子面板。
3. 完成缺失值处理、去极值、中性化、标准化及正交处理。
4. 计算滚动 Rank IC、ICIR 和 IC 正向占比，形成动态因子权重与综合得分。
5. 按行业—市值分层抽样生成目标持仓，计算月度收益及绩效汇总。

## 环境和限制

- 原项目使用平台内的 `jqdata`、`jqfactor`；本地 `jqdatasdk` 需要独立认证和接口适配，不等同于聚宽回测引擎。
- 数据可用范围与调用额度取决于账号权限及平台条件；能够下载数据不等于有权重新分发。
- 财务数据公告时点、历史修订、行业口径与价格复权方式可能影响复现结果。
- 原项目材料记录的研究端区间为 2010-01-29 至 2026-06-15，交易验证区间为 2015-01-05 至 2026-06-15，二者应分别报告。
- 原项目未对全部财务指标额外进行公告日滞后调整，严格时点检验仍有待完善。

官方参考：[JQData SDK](https://github.com/JoinQuant/jqdatasdk)。

# 项目研究报告

本目录用于上传匿名化的项目研究报告，当前尚未上传报告正文。

建议文件名：`项目研究报告_公开版.pdf`。

公开版应保留研究问题、方法、参数、结果、局限与参考文献，并检查：

- 封面、正文、页眉页脚中的学号、班级、联系方式等身份信息。
- Word/PDF 作者、批注、修订记录及其他个人元数据。
- 截图中的账户信息、个人路径与不宜公开的数据。
- 引用的券商研报仅列参考文献，不附研报原文或大段复制内容。
- 历史报告业绩与后续修订代码分开标注，不将旧结果作为新代码已验证的表现。

完成上述处理后，在本目录点击 **Add file → Upload files** 上传公开版 PDF。
